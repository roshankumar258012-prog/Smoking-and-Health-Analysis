# 🚬 Smoking & Health Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing the relationship between smoking habits, patient demographics, and health conditions using **Power BI**.

The interactive dashboard provides insights into smoking patterns, BMI, cholesterol levels, blood pressure risk categories, and organ-wise health conditions.

## 🎯 Project Objectives
- Analyze smoking status distribution among patients.
- Identify current smokers across different age groups.
- Compare BMI and systolic blood pressure by gender.
- Analyze average cholesterol across blood pressure risk categories.
- Examine organ-wise health condition distribution.
- Understand patient demographics and health patterns.

## 📊 Dashboard KPIs
The dashboard includes four key performance indicators:

- **Total Patients:** Number of unique patients.
- **Current Smokers:** Number of patients currently smoking.
- **Average BMI:** Average Body Mass Index.
- **Average Cholesterol:** Average cholesterol level (mg/dL).

## 📈 Visualizations
The dashboard contains six major visualizations:

1. Smoking Status Distribution Among Patients – Donut Chart
2. Current Smokers by Age Group – Column Chart
3. BMI vs Systolic Blood Pressure by Gender – Scatter Chart
4. Patient Distribution by Age Group – Bar Chart
5. Organ-wise Health Condition Distribution – Treemap
6. Blood Pressure Risk Category Distribution – Pie Chart

## 🎛️ Interactive Slicers
Users can filter dashboard data using:

- Gender
- Age Group
- Smoking Status
- Blood Pressure Risk Category
- Diagnosis Date
- Region

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Cleaning and Transformation

## 💡 Key Insights
The dashboard helps users explore:
- Smoking patterns across different age groups.
- Differences in health indicators among patients.
- Distribution of recorded health conditions across organs.
- Relationships between BMI and systolic blood pressure.
